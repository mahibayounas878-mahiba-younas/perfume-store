# Maison Parfum

1. Open this folder in VS Code (File > Open Folder).
2. Open the terminal (Ctrl + `) and run:
   npm install
   npm start
3. Visit http://localhost:3000

Structure
- server.js          Express backend (API + serves the site)
- data/fragrances.json   Edit products here
- data/orders.json       Orders are saved here
- public/            Frontend (index.html, app.js, images/)
